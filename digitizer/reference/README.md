# Reference DSTs

Drop your own hand-digitized embroidery files here (DST/PES/EXP/JEF — any
count). Pair a file with its source artwork (PNG/JPG/SVG, same basename)
when you have it — that enables the strongest style comparison.

These get analyzed for house style — stitch lengths, bean/satin habits,
underlay, fill density, ties, travel-vs-trim thresholds — which then
calibrates ../digitize.py.
